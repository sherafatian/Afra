# اعتبارسنجی — ۲۹ آبان ۱۴۰۵

این‌ها شواهد محدود توسعه‌اند و جای پذیرش تولید یا ممیزی امنیت را نمی‌گیرند. همه حساب‌ها و داده‌ها ساختگی بودند؛ به سرور سازمان متصل نشدیم.

- آزمون لاراول روی PostgreSQL17 واقعی:۳۱آزمون و۲۷۳بررسی موفق. دستور `php artisan test --compact` باید فقط با دیتابیس آزمایشی مستقل `afra_test` اجرا شود. `RefreshDatabase` جدول‌های آزمایش را بازسازی می‌کند؛ اتصال آن به داده عملیاتی ممنوع است.
- فرانت:۴آزمون Vitest، ساخت سخت‌گیرانه TypeScript/Vite و بررسی قالب سورس موفق‌اند. در FrontEnd دستورهای `npm ci`، `npm run format:check`، `npm test` و `npm run build` اجرا شوند. هشدار حجم بسته Ant Design باقی است؛ تفکیک بیشتر مسیرها مطلوب است.
- مرورگر واقعی: ویرایش گروه/نقش/عضویت، تخصیص مسئول و جانشین، بازبینی مستقل، بارگذاری شاهد توسط آزمایشگر و ثبت نتیجه و دریافت از تاریخچه. بایت‌های فایل دریافت‌شده با SHA256 برابر `0304d2668aed66916ed58fbf5e489844afacb1ba5791a2a11cc3e942c6383fe6` یکسان بودند. فایل مرورگر متن کوچک بود؛ مرز۲۰MiB جداگانه در آزمون بارگذاری لاراول و دریافت جریانی بررسی شد و ادعای آزمون HTTP بیست‌مگابایتی استقرار نداریم.
- ویرایشگر دسترسی فارسی در۳۹۰×۸۴۴ و انگلیسی در۱۴۴۰×۱۰۵۰: بدون بیرون‌زدگی افقی سند، عملیات ذخیره داخل صفحه، بدون خطای جاوااسکریپت یا API ناموفق. منطقه زمانی مرورگر تهران بود. تصاویر در `docs/screenshots` هستند.
- راهنمای Word: فهرست پویای بومی، وزیر معمولی/ضخیم تعبیه‌شده، تعیین Cambria برای لاتین، بازبینی جلد و ثبات شماره‌های فهرست. چون Cambria اختصاصی روی محیط نصب نیست، PDF محلی فونت جایگزین دارد. راهنمای فارسی۲۲صفحه و انگلیسی۱۸صفحه است.

## تکرار بررسی مرورگر

Python Playwright و Chromium در `/usr/bin/chromium` لازم‌اند. API و Vite محلی را با داده آموزشی اجرا کنید. متغیرهای `AFRA_TEST_URL`، `AFRA_TEST_EMAIL`، `AFRA_TEST_PASSWORD_FILE` (مسیر فایل رمز بیرون مخزن) و در صورت نیاز `AFRA_SCREENSHOT_DIR` تعیین شوند. رمز را در مخزن قرار ندهید.

`python FrontEnd/tests/access_responsive.py` فقط خواندنی است و مدیر آموزشی با حداقل یک گروه موجود می‌خواهد. `python FrontEnd/tests/evidence_roundtrip.py` نتیجه و پیوست **ثبت می‌کند**؛ فقط پروژه ساختگی دورریختنی، آزمایشگر تخصیص‌یافته و اجرای موجود استفاده شود. روی تولید اجرا نشود. این اسکریپت‌ها حساب ایجاد یا اختیار اعطا نمی‌کنند.

`PHP_BINARY=php python scripts/build_openapi.py` پیش‌نویس OpenAPI مسیرهای موجود را از لاراول می‌سازد. سرویس بیرونی تکمیل‌نشده در آن تعریف نشده؛ طرح برخی ورودی‌های حساب/رکورد هنوز کامل نیست.

فهرست الزامی کارهای باقی‌مانده در مستند وضعیت پیاده‌سازی آمده است. ظرفیت۱۰۰هزار حساب و آمادگی کامل استقرار هنوز اثبات نشده‌اند.
