# پذیرش انتشار — آماده نیست

انتشار کامل درخواستی هنوز پذیرفته نشده است. آمادگی زیرساخت جای پذیرش امکانات را نمی‌گیرد. راهنماهای کاربری در این مرحله عمداً بدون تغییر مانده‌اند.

| حوزه | شاهد / مانع باقی‌مانده |
|---|---|
| تست، بازبینی، اجرا و خطا | آزمون متمرکز API/مرورگر موفق؛ پذیرش کامل وضعیت‌ها و مالکیت هنوز لازم است. |
| مجوز پروژه/بخش/عملیات | رگرسیون فعلی موفق؛ باید به همه ماژول‌ها و گزارش‌های تکمیل‌نشده گسترش یابد. |
| نسخه و سازگاری نیازمندی | رابط/API، اثر تغییر فیلترشده، پیوند ثابت اجرا، رد بازبینی قدیمی و جداسازی Pass قدیمی پیاده‌اند؛ پوشش تاریخی/مبنای پیکربندی باقی است. |
| مراحل مشترک، قالب، داده، فیلد و نما | نسخه بازبینی‌شده، به‌روزرسانی مصرف‌کننده و گردش کامل نوع‌دار باقی است. |
| برنامه و پیکربندی | دامنه پویا، اثرانگشت پیش‌نمایش، گسترش تست/پیکربندی/داده و تجمیع حالت الزامی باقی است. |
| حساب و پروفایل | مدیریت حساب و بازنشانی پیاده‌اند؛ هویت و حریم خصوصی کد ملی، تصویر و انتخاب‌گر تقویمی کامل باقی‌اند. |
| نشست | CSRF اولیه، اتصال به هویت/نشست، Web Locks، خروج هماهنگ، کلید قبلی و ابطال زنده آزمون دارند؛ پذیرش جامع مرورگر/امنیت لازم است. |
| همکاری و پیش‌نویس اجرا | گفتگو، اشاره، اعلان، توقف/ادامه/زمان‌گیری و پیش‌نویس ادامه‌پذیر باقی‌اند. |
| کیفیت و گزارش | شرط انتشار، ماتریس تاریخی، گزارش غنی و خروجی کامل چاپ/PDF باقی‌اند. |
| ورود و خروج داده | پیش‌نمایش و اعتبارسنجی و ثبت تراکنشی CSV/XLSX باقی است. |
| سرویس داخلی اکسپوزی | مصرف‌کننده، راز، اشتراک مجوز پروژه/دامنه، تفویض، تکرارپذیری و گزارش مصرف واقعی باقی‌اند. |
| استقرار | الگوهای بومی Nginx/FPM، Supervisor و IIS/FastCGI/ARR ارائه‌اند؛ پذیرش سرور واقعی، TLS، مجوز NTFS و کارگر اجرا نشده است. |
| ظرفیت و بازیابی | آزمون بار اندازه‌گیری‌شده۱۰۰هزار حساب و بازیابی آزمایشی اجرا نشده‌اند. عملیات مسئول پشتیبان است؛ قطعه رمز‌شده و تاریخچه کلید حفظ شود. |

برای ادامه پیاده‌سازی سورس به رمز تولید، داده واقعی یا اتصال سرور سازمان نیاز نیست. هیچ سرور سازمانی تغییر نکرده است. `/api/ready` و `afra:check` فقط آمادگی وابستگی/تنظیم را می‌سنجند و پذیرش انتشار را صریحاً ناتمام اعلام می‌کنند. وجود فرم یا ذخیره‌سازی عمومی، تحویل گردش کامل ماژول محسوب نشود.
